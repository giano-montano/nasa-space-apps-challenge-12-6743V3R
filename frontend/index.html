Sobre este lugar

Elige uno de los casos de prueba o busca un lugar del cielo.

La "huella de colores" de una fuente: cuánta luz tiene en cada longitud de onda. Cada punto es una foto de SPHEREx.

Las líneas punteadas marcan dónde suelen estar el agua, el metano o el CO; no significan que se hayan detectado.

¿Cambió de brillo? Se compara cada fecha con otra en el mismo color. Útil para RW Aurigae y R Draconis, que no se mueven pero varían.

Son candidatos para revisión humana, no descubrimientos. La herramienta solo señala; una persona decide.
¿Qué tan bien detecta? (prueba con objetos simulados)

Añadimos objetos falsos que se mueven sobre estas imágenes reales y contamos cuántos encuentra. Así decimos con honestidad hasta dónde llega.

El mismo lugar visto por otros telescopios (Aladin Lite, CDS Estrasburgo).
